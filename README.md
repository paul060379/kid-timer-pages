# Kid Timer

Kid Timer 是給小朋友使用的視覺化倒數計時器。設定時間後，用逐漸下降的水位理解還剩多久。

立即使用：[Kid Timer](https://paul060379.github.io/kid-timer-pages/)

## Install on your phone

Kid Timer 是 Progressive Web App（PWA），不需要 App Store 或 Google Play，也能加入手機主畫面，之後像一般 App 一樣開啟。

### iPhone / iPad

1. 使用 Safari 開啟 [Kid Timer](https://paul060379.github.io/kid-timer-pages/)。
2. 點 Safari 的分享按鈕。
3. 選擇「加入主畫面」。
4. 確認加入。
5. 從 iPhone 或 iPad 主畫面開啟 Kid Timer。

加入後會以獨立 App 視窗開啟。

### Android

1. 使用支援 PWA 的瀏覽器開啟 [Kid Timer](https://paul060379.github.io/kid-timer-pages/)。
2. 開啟瀏覽器選單。
3. 選擇「安裝應用程式」或「加到主畫面」。
4. 確認安裝。
5. 從 Android 主畫面開啟 Kid Timer。

如果瀏覽器主動顯示 Install，可以直接使用該安裝流程。App 內的「設定 → 加入手機主畫面」也會在支援時開啟原生安裝提示。
